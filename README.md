# @amiral-corelab/acl

**@amiral-corelab/acl** is an Angular library designed to support the development of laboratory-oriented applications by
providing a consistent and structured foundation across the frontend stack.

The design system is fully handcrafted and built with APCA contrast guidelines in mind.
